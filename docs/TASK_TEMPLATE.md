# Task request template

**Goal:** [What should be working when finished?]
**Scope:** [Modules or services; or ask agent to discover]
**Constraints:** Preserve existing behavior, code style, and uncommitted changes.
**Acceptance criteria:** [Observable outcomes]
**Environment:** Local / staging / production (production changes require separate approval).
**Autonomy:** Inspect, plan, implement, test, review and document without asking for routine reversible decisions. Ask before destructive or live changes.
**Final report:** Files changed, exact checks/results, remaining risks and deployment steps.

Example: Use the engineering-team skill to add a secure task management CRUD API and responsive React UI. Detect the existing stack and conventions. Include validation, authorization and tests. Do not modify production data or deploy. Report verified results.
